# docs/

文档分三类，各管一件事：

| 目录 / 文件 | 内容 | 谁看 |
| --- | --- | --- |
| [`commands.md`](commands.md) | 每个 `ww` 子命令的用法、行为、边界 | 使用者 |
| [`adr/`](adr/) | 架构决策记录：为什么这样做、当时有哪些替代方案 | 改代码的人 |
| [`agents/`](agents/) | 给 AI agent 的约定：issue 流程、triage 标签、领域文档布局 | agent |

## 约定

- **ADR 只增不改**：决策变了就写新的一份，旧的标成「被 ADR-000N 取代」；文中「当时」的表述保留原样
- **`commands.md` 随代码走**：加/改子命令时同步更新，它是对外唯一的行为说明
- `agents/` 里的文件由 skill 读取，路径写在仓库根的 `AGENTS.md` 里，改名要一起改

## 不在 docs/ 里的

- `README.md`（仓库根）：面向使用者的入口，只放安装、平台支持、常用命令
- `AGENTS.md`（仓库根）：给 agent 的硬约束，比 `docs/agents/` 更具体
